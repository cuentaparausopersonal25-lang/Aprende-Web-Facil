PRIMEROS CONCEPTOS

¿Qué significa programar?

Programar es darle instrucciones claras a una computadora para que realice una tarea. Esas instrucciones se organizan en pasos y se escriben siguiendo las reglas de un lenguaje.

Ejemplo cotidiano: preparar un mate requiere seguir pasos ordenados: calentar el agua, colocar la yerba, acomodarla y cebar. En programación, un algoritmo es una secuencia de pasos que busca resolver un problema.
01

¿Qué es el código?

El código es un conjunto de instrucciones escritas en un lenguaje. Por ejemplo, en Python podemos escribir:

print("¡Hola, mundo!")

La función print() muestra en pantalla el texto que está entre comillas.

02

Los lenguajes principales del desarrollo web

HTML

Organiza el contenido: títulos, párrafos, imágenes y enlaces.

<h1>Mi primera web</h1>
CSS

Define la apariencia: colores, tamaños, espacios y distribución.

h1 { color: blue; }
JavaScript

Agrega interacción y responde a acciones.

alert("¡Hola!");
Python

Permite crear programas y servidores web, por ejemplo con Flask.

nombre = "Ana"
print(nombre)
03

Cómo se organiza un proyecto

En una aplicación Flask, el servidor puede estar en app.py, las plantillas HTML en templates y los archivos de diseño y comportamiento en static.

mi-proyecto/
├── app.py
├── templates/
│   └── index.html
└── static/
    ├── css/
    │   └── style.css
    └── js/
        └── main.js

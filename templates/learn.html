Antes de escribir código, entendamos la idea

Programar es darle instrucciones claras a una computadora para que realice una tarea.

01

¿Qué significa programar?

Cuando programás, dividís un problema en pasos y escribís instrucciones que la computadora puede ejecutar. Por ejemplo, una aplicación del clima recibe una ciudad, busca información y muestra la temperatura.

Ejemplo cotidiano: para preparar un mate seguís pasos: calentar agua, colocar yerba, acomodarla y cebar. Un algoritmo funciona de manera parecida: tiene pasos ordenados y un objetivo.
02

¿Qué es el código?

El código es el conjunto de instrucciones escritas en un lenguaje que una computadora puede interpretar o ejecutar. Cada lenguaje tiene reglas propias, como la gramática de un idioma.

print("¡Hola, mundo!")

Este ejemplo está escrito en Python. La instrucción print() muestra en pantalla el texto que está entre comillas.

03

Los lenguajes para crear páginas web

HTML

Organiza el contenido: títulos, párrafos, imágenes y enlaces.

<h1>Mi primera web</h1>
CSS

Define la apariencia: colores, tamaños, espacios y distribución.

h1 { color: blue; }
JavaScript

Agrega acciones: responder a clics, validar formularios y actualizar contenido.

alert("¡Hola!");
Python

Permite crear programas y servidores web, por ejemplo con Flask.

nombre = "Ana"
print(nombre)
04

Cómo se construye una página

HTML define qué elementos existen, CSS define cómo se ven y JavaScript define cómo reaccionan. En proyectos con Flask, Python puede preparar la información y enviarla a las plantillas HTML.

mi-proyecto/
├── app.py
├── templates/
│   └── index.html
└── static/
    ├── css/
    │   └── style.css
    └── js/
        └── main.js

Separar responsabilidades hace que el código sea más fácil de mantener.

05

Tu primera práctica

Escribí este archivo en un editor de texto. Guardalo como hola.html y abrilo con tu navegador.

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <title>Mi primera página</title>
</head>
<body>
  <h1>¡Estoy aprendiendo!</h1>
  <p>Este es mi primer paso programando.</p>
</body>
</html>
Desafío: cambiá el título, escribí un párrafo y agregá un subtítulo con la etiqueta h2.

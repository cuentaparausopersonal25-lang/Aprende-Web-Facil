¿TENÉS DUDAS?

Preguntas frecuentes.

Si recién estás empezando, es normal tener preguntas. Acá respondemos las más comunes.

¿No encontrás tu respuesta? Consultanos →
¿Qué necesito para comenzar?+

Una computadora, conexión a Internet, un navegador y ganas de aprender. Más adelante te mostraremos cómo instalar las herramientas gratuitas que vamos a utilizar.

¿Necesito saber programar?+

No. Los cursos están pensados para personas que empiezan desde cero. Vamos a explicar cada concepto antes de usarlo.

¿Qué es HTML?+

Es el lenguaje de marcado que organiza el contenido de una página web, como títulos, párrafos, imágenes y enlaces.

¿Qué es GitHub?+

Es una plataforma para guardar, organizar y compartir proyectos de programación utilizando Git.

¿Cómo publico mi página?+

Podés guardar el proyecto en GitHub y conectarlo con un servicio como Render. En el curso de publicación lo vemos paso a paso.

¿Qué es Render?+

Es una plataforma que permite desplegar aplicaciones y sitios web para que otras personas puedan visitarlos mediante una dirección pública.

NO TE FRUSTRES

Los errores también enseñan.

Algunos problemas habituales y cómo empezar a resolverlos.

HTML

La página no muestra los cambios

Puede que no hayas guardado el archivo o que el navegador esté mostrando una versión anterior.

Probá esto:

Guardá el archivo y recargá el navegador. Si hace falta, usá Ctrl + F5.

CSS

Los estilos no aparecen

La ruta del archivo CSS puede estar mal escrita o el nombre no coincide.

Probá esto:

Revisá el atributo href del link y comprobá que el archivo exista en esa carpeta.

FLASK

TemplateNotFound

Flask no encuentra una plantilla que intentás mostrar.

Probá esto:

Comprobá que la carpeta se llame templates y que el archivo tenga el nombre correcto, por ejemplo index.html.

RENDER

Internal Server Error

La aplicación encontró un problema al ejecutarse en el servidor.

Probá esto:

Abrí los logs de Render y buscá el último error. Revisá dependencias, rutas y nombres de archivos.

PARTE 2 · EJEMPLO DE CÓDIGO

Leamos el código juntos

Primero leelo completo. Después identificá qué tarea cumple cada bloque. No hace falta memorizarlo: lo importante es comprenderlo.

{{ lesson.code }}
Cómo analizar un ejemplo
  1. Identificá: buscá dónde empieza y termina cada bloque.
  2. Comprendé: preguntate qué tarea cumple cada línea.
  3. Modificá: cambiá un texto, número, color o nombre.
  4. Probá: ejecutá el código y observá el resultado.
  5. Corregí: revisá comillas, paréntesis, etiquetas, nombres y rutas si algo falla.
{% if course.slug == "html" %}
Guía de las etiquetas del ejemplo:
  • <!DOCTYPE html>: declara el uso de HTML5.
  • <html lang="es">: contiene el documento e indica el idioma.
  • <head>: reúne configuración e información de la página.
  • <meta charset="UTF-8">: permite mostrar correctamente letras y símbolos.
  • <title>: define el texto de la pestaña del navegador.
  • <body>: contiene el contenido visible.
  • <h1>: crea el título principal; <p> crea un párrafo.
  • <a href="...">: crea un enlace.
